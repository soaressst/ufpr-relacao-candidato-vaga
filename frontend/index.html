Como trabalhamos

Dos dados às ideias, das ideias às soluções

Difundimos a ciência de dados no ambiente universitário com projetos práticos, estudo em grupo e conteúdo aberto.

A partir de dados

Coletamos e conferimos dados oficiais, sempre com a fonte rastreável.

Surgem ideias

Exploramos, testamos hipóteses e medimos o quanto cada resultado é confiável.

Viram soluções

Entregamos ferramentas abertas: apps, painéis e relatórios que qualquer pessoa pode usar.
